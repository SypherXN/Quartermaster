# Quartermaster

Planned native OpenCode V2 plugin for assigning agent models using preference plans and provider availability. Standalone routing comes first, followed by OMO Slim integration and an optional GUI.

See [implementation plan](docs/IMPLEMENTATION_PLAN.md) and [ID tracker](.cursor/plans/quartermaster.plan.md). No plugin code exists yet. The live local `opencode-usage.json` snapshot is intentionally excluded from Git.
