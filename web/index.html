03Provider inventory

Providers & models.

Browse OpenCode’s provider catalog. Compare capabilities and exact named variants. Catalog metadata does not establish connectivity.

Refresh the catalog to see provider metadata. No inference calls are made.

Reading browser shortlist…

The thinking badge uses OpenCode’s capability flag when the catalog sends one. Otherwise it reads known effort IDs — none, minimal, low, medium, high, xhigh, max, thinking — and Cursor names that end in those efforts. Fast and context sizes are not thinking. Any other name stays Thinking unknown. Plans store the exact variant ID. Enabled metadata is not proof of connectivity or availability.
